# 紅樓推理 · 五幕

以《紅樓夢》**程甲本**为底的推理向单文件网页作品。五幕各自独立成篇，按顺序推进；附《人物小传》一册。

## 怎么玩

打开 `index.html`（合卷）→ 从第一幕开始。
每幕都是一次"读原文 → 找破绽 → 下判词"的过程：题面全部落在原著情节里，答案都能回指原文。

- 电脑与手机均可，建议横屏、全屏
- 进度存在浏览器本地（`hongluo.rustylake.v1`），换设备或清缓存会重置
- 无需安装、无需登录、无外部依赖；断网也能玩

## 技术说明

- 纯静态：单个 HTML + 内联 SVG／内联 PNG（无外链图片、无 CDN、无字体文件）
- 无构建步骤：clone 下来直接开 `index.html` 即可
- 存档只写 `localStorage`，不上传任何数据
